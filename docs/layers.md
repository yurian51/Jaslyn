# Jaslyn System Layers

Jaslyn is built as an independent agent system, not a clone of another assistant.

## Completed boundaries
- Mind: intent, objectives, decisions, self-check.
- Agency: autonomy modes, bounded loops, background tasks, recovery.
- Memory: typed memories and contextual retrieval.
- Action: explicit tool registry and execution boundary.
- Governance: policy, risk and audit.
- Verification: evidence-based outcome checking.
- Interface: channel-neutral request contracts.

The implementation deliberately separates decision-making, side effects and verification so each can evolve independently.
